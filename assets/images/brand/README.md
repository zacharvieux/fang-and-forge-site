# Fang & Forge Brand Assets

This folder stores the public-facing brand assets used by the Fang & Forge Productions website.

## Primary logo

Upload the selected company logo to this folder using this exact filename:

`fang-and-forge-primary-logo.png`

Expected repository path:

`assets/images/brand/fang-and-forge-primary-logo.png`

## Intended use

The primary logo may be used for:

- the website header and homepage
- About / Who We Are sections
- Discord links and community areas
- GitHub branding
- public-facing documents and promotional material

## Future brand assets

Additional logo variants can be added here later, such as:

- `fang-and-forge-emblem.png`
- `fang-and-forge-logo-transparent.png`
- `fang-and-forge-logo-dark.png`
- `fang-and-forge-favicon.png`

Keep filenames lowercase and hyphen-separated for consistency.
