# Fang & Forge Productions

Public studio website and world portal for Fang & Forge Productions.

## Purpose

This site will introduce Fang & Forge, showcase current and future worlds such as Veyra, link to active projects, and provide a foundation for future supporter/member content.

## Stack

- Astro 7
- TypeScript
- Static-first architecture
- Content-driven world pages

## Development

```bash
npm install
npm run dev
```

The site is currently in its initial architecture and design phase.
